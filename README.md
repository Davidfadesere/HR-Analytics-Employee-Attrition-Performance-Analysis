## Project Overview
This project analyzes employee data to identify key factors contributing to attrition and evaluate performance trends. The goal is to provide actionable insights that help HR departments improve retention strategies.

## Dataset
The dataset includes employee demographics, job roles, salary, tenure, and attrition status.

Tools Used: Excel and Power BI

## Key Questions Addressed
What is the overall attrition rate across different departments?

Does compensation (Salary) significantly impact employee turnover?

How do years since the last promotion affect retention?

## Process
Data Cleaning: Handled missing values and standardized categorical data (e.g., Ethnicity, Education Field).

Exploratory Data Analysis (EDA): Visualized correlations between distance from home and job satisfaction.

Insights: Identified that employees in specific roles (e.g., Sales) with high overtime show higher attrition risks.

## Recommendations
Implement stay-interviews for departments with attrition rates above 15%.

Review promotion cycles for mid-level roles to boost engagement
